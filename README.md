# Mibl Launcher 2.7.0

Локальный лаунчер Minecraft с поддержкой модов, сборок, шейдеров и ресурспаков.

## Особенности

- Запуск Minecraft с оптимизацией Ultra FPS
- Установка модов, шейдеров и ресурспаков из Modrinth и CurseForge
- Поддержка сборок (modpacks)
- Официальный вход Microsoft (лицензия) и аккаунты Ely.by
- Мультиязычность: 10 языков интерфейса
- Выбор языка игры до запуска — настройка записывается в `options.txt`
- HUD-редактор кнопок и элементов интерфейса
- Новогодняя тема с интерактивными гирляндами, снегом и ёлкой
- Редактор тем и настроек
- Просмотр профилей игроков

## Сборка

Для сборки проекта необходимы:

- Node.js 18+
- Rust 1.77+
- Tauri CLI

```bash
npm install
npm run tauri build
```
