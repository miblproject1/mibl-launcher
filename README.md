### ✨ Features / Основные возможности
- **🔐 Microsoft & Ely.by Auth:** Official Microsoft OAuth 2.0 Device Code login, Ely.by integration, and offline mode.
- **🎨 Full UI Customization:** Custom fonts (`Pixelify Sans`, Monospace, Rounded, or your own `.ttf`/`.otf` files), UI text scaling, custom image/video wallpapers, and background music player.
- **🌍 Multi-language Interface (i18n):** Instant switching between **English**, **Русский**, and **Українська**.
- **📦 Modrinth & CurseForge:** Search and install mods, shaders, resource packs, and modpacks in one click.
- **🧍 3D Skin Viewer & HUD Editor:** Clean home screen with interactive 3D character preview and customizable button layout.

### 📥 Download / Скачать
Download the latest Windows installer (**`Mibl.Launcher_2.5.0_x64-setup.exe`**) from the [Releases](https://github.com) page.

---

### 🛠️ Build from Source / Сборка из исходников
Requirements: **Node.js 18+**, **Rust 1.77+**, **Tauri CLI**.

```bash
npm install
npm run tauri build
```
