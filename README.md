# Mibl Launcher 2.4

Локальный лаунчер Minecraft с поддержкой модов и сборок.

## Особенности

- Запуск Minecraft с оптимизацией Ultra FPS
- Установка модов из Modrinth
- Поддержка сборок (modpacks)
- Редактор тем и настроек
- Просмотр профилей игроков

## Сборка

Для сборки проекта необходимы:

- Node.js 18+
- Rust 1.77+
- Tauri CLI

```bash
npm install
npm run tauri build
```
